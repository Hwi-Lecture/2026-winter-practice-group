통합 검색 에이전트 실습

메일·설명서·신청자 표를 검색하는 도구 중 무엇을 쓸지 Claude가 직접 정하고, 필요하면 여러 번 이어서 사용합니다.

사용할 자료 (도구)

동작 방식
  • 켜 둔 자료의 검색 도구만 Claude에게 알려 줌
  • 어떤 도구를 쓸지, 몇 번 쓸지, 언제 멈추고 답할지는 Claude가 정함
  • 앱은 Claude가 요청한 도구를 실행해 결과를 돌려주기만 함 (도구 사용은 질문 하나에 최대 8번)
살펴볼 점
  • 질문마다 어떤 자료의 도구를 골랐는지
  • 두 자료를 함께 봐야 하는 질문에서 도구를 이어서 쓰는지, 자료끼리 내용이 다를 때 알려 주는지
  • ‘Claude에게 보낸 내용 보기’에서 호출할 때마다 이전 도구 결과가 쌓여서 함께 보내지는 모습
  • 자료 하나를 끄고 같은 질문을 했을 때 다른 자료로 답하려 하는지, 확인할 수 없다고 하는지
  • 메일 검색에서 원하는 메일이 안 나오면 검색어를 바꿔 다시 찾는지
