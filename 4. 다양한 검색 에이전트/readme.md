## 개요
RAG 에이전트 강의에 들어가기 전, 다양한 소스를 바탕으로 질문에 답하는 에이전트를 만들어 보는 실습입니다.
지식 에이전트를 구축하는 방법이 RAG만 있는 것은 아니라는 점을 보여주려는 목적으로 구성했습니다.
