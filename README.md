## 폴더 구성

| 폴더 | 내용 |
|---|---|
| `1. 에이전트실습` | 에이전트에게 맡길 정리용 더미 파일 (`1. 파일정리`, `2. 엑셀정리`) |
| `2. 나를 따라하는 챗봇` | 페르소나 챗봇 사이트 (`persona-site`) |
| `3. 에이전트 구현하기` | Streamlit 기반 에이전트 앱 (`app.py`, `데이터`) |
| `4. 다양한 검색 에이전트` | 텍스트 추출 실습, 메일·설명서·신청자 표를 검색해 답하는 챗봇 실습 4종 |

## 실행 전 준비

- 폴더 2, 3, 4는 Anthropic API 키가 필요합니다.
- 각 폴더의 `.env.example`을 `.env`로 복사한 뒤 키를 입력하세요. (폴더 4는 `4. 다양한 검색 에이전트/2. 검색 가능한 문서/.env.example`)
- `.env`는 git에 올라가지 않습니다. 키를 커밋하지 마세요.

|---|---|---|
