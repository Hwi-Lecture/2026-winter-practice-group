# 2026 겨울 실습 파일 모음

풍덕천학당 교안에서 사용하는 실습 파일 모음입니다.

## 폴더 구성

| 폴더 | 내용 |
|---|---|
| `1. 에이전트실습` | 에이전트에게 맡길 정리용 더미 파일 (`1. 파일정리`, `2. 엑셀정리`) |
| `2. 나를 따라하는 챗봇` | 페르소나 챗봇 사이트 (`persona-site`) |
| `3. 에이전트 구현하기` | Streamlit 기반 에이전트 앱 (`app.py`, `데이터`) |

## 실행 전 준비

- 폴더 2, 3은 Anthropic API 키가 필요합니다.
- 각 폴더의 `.env.example`을 `.env`로 복사한 뒤 키를 입력하세요.
- `.env`는 git에 올라가지 않습니다. 키를 커밋하지 마세요.

### 3. 에이전트 구현하기
`실행.bat`을 더블클릭하면 패키지 설치 후 앱이 실행됩니다. Python이 필요합니다.

### 2. 나를 따라하는 챗봇
`persona-site/README.md`를 참고하세요.
